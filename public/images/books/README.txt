# Folder Cover Buku (Book Covers)
Simpan file cover buku asli di folder ini dengan nama file sesuai ID buku (contoh: `book-1.jpg`, `book-2.jpg`, dst.).

Ukuran yang direkomendasikan:
- Rasio: 3:4 atau Standar UNESCO B5 (1:1.414)
- Dimensi piksel: 800 x 1130 px (atau 600 x 850 px)
- Format: JPG / PNG / WebP (Maks 300 KB untuk performa optimal)
